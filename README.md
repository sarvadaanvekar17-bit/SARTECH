# SARTECH — Personal Monitor(Tracker)

**A productivity dashboard designed to help you organize tasks, track daily progress, and stay focused.**

SARTECH is a personal productivity web application built using HTML, CSS, and JavaScript. It brings essential productivity tools together in one clean, modern dashboard, helping users manage tasks, monitor their progress, and maintain focus throughout the day.

## ✨ Features

- **Task Management:** Add and organize tasks from one dashboard.
- **Task Search & Filtering:** Find tasks and filter them by status or category.
- **Productivity Statistics:** Monitor task progress and daily productivity.
- **Pomodoro Focus Timer:** Use a 25-minute timer for focused work sessions.
- **Dark & Light Mode:** Switch between visual themes.
- **Local Storage:** Preserve supported data across browser refreshes.
- **Responsive Design:** Use the dashboard on desktop and smaller screens.
- **Personalized Dashboard:** Display a personalized greeting and current date.
- **Sidebar Navigation:** Navigate dashboard sections easily.

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## 🚀 Getting Started

1. Clone or download the repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser, or use the Live Server extension.
